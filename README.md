KrigInv — Kriging-based Inversion for Deterministic and Noisy Computer Experiments

This repository is the regular KrigInv package repository (available at https://CRAN.R-project.org/package=KrigInv).
It contains the latest sources, possibly some supplement of stable CRAN release.

Installation
------------

You can install the standard (CRAN) version of the code:

```r
install.packages("KrigInv")
```

You can install the latest (this repository) version of the code with the `remotes` R package:

```r
install.packages("remotes") # Install remotes, if you haven't already.
remotes::install_github("KrigInvTeam/KrigInv")
```
